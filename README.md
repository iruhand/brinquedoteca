# Brinquedoteca do Papai

App de brincadeiras para celular e tablet (PWA): instala na tela inicial, abre em tela cheia e funciona sem internet depois da primeira visita.

Endereço: https://iruhand.github.io/brinquedoteca/

Estes arquivos são montados a partir da Brinquedoteca no Claude e substituídos a cada versão nova (o histórico das versões fica em `versao.json`). Não é preciso editar nada aqui à mão.
